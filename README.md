# 七台河短道速滑训练基地 · 数据采集与分析项目

短道速滑队长期干预实验的数据采集、清洗、分析与报告工程。
覆盖：CPET 最大摄氧量测试、训练心率监测、晨脉恢复、血液生化、前测素质与统一数据集。

## 一键重建

```bash
# 使用工作区捆绑 Python
python build_all.py
```

脚本按依赖顺序依次运行：心率解析 → 新 CPET 清洗/合并 → 深度分析 → 交互仪表盘 →
图文周报 → 综合周报（可选心率周对比/教练简报表），每步打印状态与耗时。

## 新增数据

### 新增 CPET 测试
1. 把 XML 放入 `最大摄氧量/最大摄氧量数据/新的最大摄氧量数据/新的最大摄氧量数据/`
2. 跑 `python build_all.py`（会自动清洗、去重、合并、重生成全部报告）

### 新增训练心率场次
1. 把设备导出的 xlsx 放入 `心率/`（文件内需含"训练名称/训练日期/团队综合报告"）
2. 跑 `python build_all.py`

## 关键口径

- **有效性分级**：有效=RER≥1.05 且递增负荷运动≥3 分钟；亚极量=RER 1.00–1.05 或不足；
  无效=未完成运动/运动过短。主分析纳入"有效+亚极量"。
- **教练C 7.28**：前段陆地+后段冰上复合场次，按 15:22（录制后 6193 秒）拆分。
- **TRIMP**：Edward 区间加权（Z1–Z5 权重 1–5），分段用整场校准系数分摊。
- **%预测值**：设备内置 Wasserman 成人方程，儿童/女生参考值偏低，跨性别比较谨慎。
