SpeedTrack Pro 教练端试用版
============================

启动（最简单）：直接双击“SpeedTrackPro.exe”，程序会自动启动并打开教练端页面
启动（推荐）：双击“启动教练端.bat”，效果相同
停止：双击“停止教练端.bat”

适合验证：
1. 训练后复盘
2. 训练数据与 500m / 7圈成绩
3. 心率负荷
4. 急性疲劳恢复（CMJ、VAS、RPE、HRV）
5. 功率自行车 / 基础体能数据

注意：
- 本版本为本机离线试用，数据保存在本目录的 blood.db，不上传网络。
- 分发包已带完整试用数据；请先解压整个文件夹，再双击程序，不要只转发快捷方式。
- 如果电脑上的 8000 端口已被占用，程序会自动换到可用端口，无需手工设置。
- 如果同目录存在旧版、不兼容的 blood.db，程序会保留原文件，并自动使用 SpeedTrackPro-data.db。
- 首次启动可能需要等待几秒；不要重复双击启动脚本。
- 关闭程序或重启电脑不会删除数据。
- 原始数据中缺少测量日期的记录保持为空，没有人为补日期。
- 试用结束后请把教练反馈集中记录：看哪些页面、哪些字段对训练决策最有用，哪些内容看不懂或不需要。
